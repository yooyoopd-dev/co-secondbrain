### 1.1 같이 나온 결함 — 모델이 표본의 front-matter 를 베낀다

**해결됨 (7번).** 규약 파일에 넣은 페이지 표본의 값을 모델이 그대로 복사한다.
회수본 6건(claude 3 · gemini 3)을 전부 세어 보니 예외가 없었다.

| 필드 | 표본 값 | 모델이 낸 값 | 문제 |
|---|---|---|---|
| `generated_by` | `claude-code` | 6/6 `claude-code` | Gemini 가 낸 페이지에도 `claude-code` 가 박힌다 |
| `updated` | `2026-09-05T00:00:00.000Z` | 6/6 같은 값 | 모든 페이지의 갱신 시각이 같은 가짜 날짜가 된다 |
| `updated_by` | `app` | 6/6 `app` | 앱이 아직 사용자를 몰라 지금은 참이다 |

처음에는 `generated_by` 만 봤는데 세어 보니 `updated` 가 더 나쁘다. [`PLAN.md`](PLAN.md) §4 의
Lint #4 "낡은 주장"은 `updated` 로 판정하는데 값이 상수면 아무것도 못 잡는다.

`core/agent/stamp.ts` 가 덮어쓴다. 사람이 diff 로 승인하기 **전에** 고친다 — 승인한 화면과

앱이 사용자 신원을 모르는데 지어내는 것보다 낫다.

## 3. 사내 문서는 반출하지 않는다 — 수치만 회수한다

17 · 18 의 원래 계획은 사내 문서와 엔티티명 목록을 개발 쪽으로 가져오는 것이었는데 반출이 불가하므로 **스크립트가 사내 PC 에서 돌고 사람이 화면에 뜬 집계 수치만 옮겨 적는 방식**으로 바꾼다. 검증에는 개수와 분포면 충분하다.

### 3.1 지켜야 할 것

- 스크립트는 **원문 텍스트 · 파일명 · 엔티티명을 출력하지 않는다.** 개수와 분포만 낸다
- 출력은 한 화면에 들어가는 표 하나여야 한다. 사람이 눈으로 확인하고 옮겨 적는다
- 파일을 만들지 않는다. 표준 출력으로만 낸다. 실수로 딸려 나갈 파일 자체를 안 만든다
- 실패한 파일은 **사유의 종류별 건수**만 센다. 사유 문자열에 경로가 섞이면 지운다

### 3.2 17번 — 추출기 자가검사가 낼 수치

| 항목 | 형태 |
|---|---|
| 확장자별 파일 수 · 성공 · 실패 | 정수 |
| 실패 사유 종류별 건수 | 사유 분류명 + 정수 |
| 파일당 조각 수 · 앵커 수 | 최소 · 중앙값 · 최대 |
| 스캔본 판정 건수 (쪽당 10자 임계) | 정수 |
| 경고 종류별 건수 | 경고 분류명 + 정수 |
| `.msg` 파싱 성공률 · xlsx 수식 셀 참조 추출 건수 | 정수 |

### 3.3 18번 — 엔티티 유사도 자가검사가 낼 수치

| 항목 | 형태 |
|---|---|
| 이름 개수 · 비교한 쌍 수 | 정수 |
| 임계 0.96 초과 쌍 수 | 정수 |
| 점수 분포 히스토그램 (0.05 구간) | 구간별 정수 |
| 길이 하한 3자 게이트에 걸린 이름 수 | 정수 |
| **오병합 건수** — 사람이 화면에서 직접 세어 입력 | 정수 |

마지막 줄이 핵심이다. 스크립트는 임계를 넘은 쌍을 사내 화면에 띄우고 사람이 그중 몇 개가
실제로 다른 대상인지 세어 그 **숫자만** 알려 준다. 이름 자체는 나가지 않는다.

## 4. 사내 PC 왕복 1회로 푸는 것

1번 스크립트를 만들면 사내에서 실행 한 번으로 아래가 한꺼번에 풀린다.

| 회수할 것 | 푸는 작업 | 형태 |
|---|---|---|
| Windows `claude --json-schema` 동작 로그 | 2 (W2) | 원시 JSON |
| Codex 원시 응답 3~5건 | **19 완성** (W3b) | 원시 JSON |
| 기업계정 Gemini 응답 3~5건 | 3 확증 | 원시 JSON |
| Gemini 쿼터 화면값 | 5 · 6 기본값 (W11) | 숫자 |
| 추출기 집계 수치 | **17** (W4 · W6) | §3.2 표 |
| 엔티티 유사도 집계 수치 | **18** (W5) | §3.3 표 |

앞의 넷은 합성 입력이라 원시 응답을 그대로 커밋해도 된다. 뒤의 둘은 §3 규칙을 따른다.

## 6. 확실하지 않은 것

- Gemini 응답 형태는 **개인 계정 n=1** 이다. 사내 기업계정은 모델 판본과 정책이 다를 수 있다
- 사내 문서 폴더에 스크립트를 돌리는 것 자체가 정책상 가능한지 확인하지 않았다
- 19번은 egress 가 열린 다른 기기가 있으면 여기서 끝낼 수 있다. 그런 기기가 있는지 모른다
- 20번 NSIS 는 Windows 빌드 환경이 필요하다. 교차 빌드 가능 여부를 확인하지 않았다
