# 디자인 시스템

출처: `design/design.md` (Inter Typography 템플릿, designmd.app). 아래는 그 명세를
데스크톱 앱에 맞게 해석한 것입니다.

## 원본 명세의 모순

`design/design.md`는 두 곳에서 서로 반대되는 지시를 합니다.

- Do's (L114): `Do Background #000000`
- Don'ts (L102): `No pure black (#000000) — use off-black or charcoal variants`

**해소안** (사용자 확인 대기):

- 앱 최하단 캔버스는 `#000000` (Do's 존중)
- 그 위에 뜨는 표면은 off-black 단계 (Don'ts의 의도인 깊이 표현 존중)

## 채택하지 않는 항목

`design.md`의 아래 규칙은 **랜딩 페이지용**이며 3-pane 데스크톱 앱에 적용하지 않습니다.

- Split-screen hero (텍스트 좌 / 비주얼 우)
- Zig-zag 교차 피처 섹션
- `clamp(4rem, 8vw, 8rem)` 섹션 세로 간격
- 1280px 중앙 정렬 컨테이너

채택하는 것은 **토큰 · 컴포넌트 · 모션** 계층입니다.

## 색상 토큰

| 토큰 | 값 | 용도 |
|---|---|---|
| `--bg-canvas` | `#000000` | 창 바탕 |
| `--bg-surface` | `#0B0B0B` | 사이드바, 패널 |
| `--bg-raised` | `#141414` | 카드, 팝오버, 입력 필드 |
| `--border` | `#262626` | 1px 경계선 |
| `--border-strong` | `#3A3A3A` | 포커스 아닌 강조 경계 |
| `--fg` | `#FFFFFF` | 본문 |
| `--fg-muted` | `#A1A1A1` | 캡션, 메타데이터 |
| `--fg-faint` | `#6B6B6B` | 비활성 |
| `--accent` | `#FFFFFF` | 활성 표시자, 기본 버튼 배경 |

의미 색상 (채도 상한 80% — `design.md` Don'ts 준수):

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ok` | `#3FB950` | 인제스트 성공, 출처 확인됨 |
| `--warn` | `#D29922` | 낮은 confidence, 낡은 주장 |
| `--danger` | `#F85149` | 모순, 충돌, 추출 실패 |
| `--info` | `#58A6FF` | 인용 링크 |

라이트 모드는 v1 범위 밖입니다. `design.md`가 `Light/Dark: ✗ No / ✓ Full`로 다크 전용을 명시합니다.

## 타이포그래피

- 본문·UI: **Inter** (앱에 번들. 사내망이라 Google Fonts CDN 사용 불가)
- 코드·메타데이터·앵커·해시: **JetBrains Mono** (번들)
- 폴백 스택: `Inter, "Segoe UI Variable", "Malgun Gothic", system-ui, sans-serif`
  — 한글 폴백이 필수입니다. Inter는 한글 글리프를 포함하지 않습니다.

| 역할 | 크기 / 굵기 | 자간 |
|---|---|---|
| 화면 제목 | 1.5rem / 700 | -0.06em (`design.md`의 tracking -6%) |
| 섹션 제목 | 1.125rem / 600 | -0.02em |
| 본문 | 0.9375rem / 400, line-height 1.6 | 0 |
| UI 라벨 | 0.875rem / 500 | 0.01em |
| 캡션·메타 | 0.8125rem / 400 | 0 |
| 모노 | 0.8125rem / 400 | 0 |

`-6%` 자간은 큰 제목에만 적용합니다. 본문에 적용하면 한글 가독성이 무너집니다.
(원본 명세의 `Tracking -6%`를 그대로 전역 적용하지 않는 이유)

위키 본문 열 폭은 `72ch` 상한 (`design.md` Body 규칙).

## 간격 · 형태

- 기본 단위 **8px**. 4px는 아이콘·라벨 등 조밀한 곳에만.
- 모서리 반경 **8px** (버튼·입력 6px, 카드·패널 8px, 모달 12px).
- 카드 그림자 `0 2px 12px rgba(0,0,0,0.6)` + 1px 경계선.
  (`design.md`는 밝은 배경 기준 `0.06` 알파라 다크에서는 보이지 않아 조정)

## 모션

`design.md` 준수:

- 200–300ms ease-out. `transform`과 `opacity`만 애니메이션 (레이아웃 유발 속성 금지).
- 진입: fade + translateY(16px→0), 420ms ease-out. 리스트는 80ms 스태거.
- 호버: 200ms 색상 변화 + 그림자 조정.
- 화면 전환: fade만, 200ms.
- **스피너 금지 → 스켈레톤 셔머.** 인제스트·질의 대기 UI 전부 스켈레톤.

## 컴포넌트 규칙

- **기본 버튼**: `--accent` 배경, 검은 글자, weight 600, 반경 6px.
  호버 8% 어둡게, 누름 시 -1px translate. 외곽 글로우 금지.
- **보조 버튼**: 1.5px 경계선 아웃라인, 배경 없음. 호버 시 은은한 배경 채움.
- **입력**: 라벨을 입력 위에. floating label 금지. 포커스 링 2px, offset 2px.
  오류 문구는 아래에 `--danger`.
- **내비게이션**: 활성 항목에 `--accent` 인디케이터, weight 500.
- **빈 상태**: 아이콘 + 설명 + 액션 버튼 구성.
- **이모지 금지.** 아이콘은 **Lucide**만 (앱에 번들, CDN 불가).

## 이 앱 고유의 컴포넌트

`design.md`에 없어 새로 정의하는 것들:

- **Diff 검토 카드** — 인제스트 승인 화면의 핵심. 페이지당 카드 1장,
  좌: 현재 / 우: 제안. 줄 단위 추가는 `--ok` 왼쪽 바, 삭제는 `--danger`.
  카드 하단에 승인 / 거부 / 편집 후 승인.
- **인용 칩** — `[^src-kickoff#slide-12]`를 모노 폰트 인라인 칩으로 렌더.
  호버 시 원문 발췌 툴팁, 클릭 시 원문 뷰어 해당 위치로 점프.
  근거가 깨진 칩은 `--danger` 취소선.
- **Confidence 배지** — high는 배지 없음(기본), medium `--warn`, low `--danger` 외곽선.
  기본값에 배지를 안 붙여야 낮은 신뢰도가 눈에 띕니다.
- **잠금 표시자** — 팀 모드에서 다른 사용자가 적용 중일 때 상단 바에
  `hong@corp 적용 중 · 12초` 표시.
